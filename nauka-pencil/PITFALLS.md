# Грабли (симптом → причина и лечение)

Пополнять при каждой новой ошибке.

| Симптом | Причина и лечение |
|---|---|
| `check`/`render`: `ffmpeg/ffprobe not found` | ffmpeg нет в PATH. Стоит `Gyan.FFmpeg` (winget); в новой оболочке путь: `~/AppData/Local/Microsoft/WinGet/Packages/Gyan.FFmpeg*/ffmpeg-*/bin` |
| Сведение звука падает с кодом 3165764104 | Взяли урезанный ffmpeg из `@remotion/compositor` (нет `f32le` и фильтров). Только полный ffmpeg |
| Рендер падает на сведении ~100 `<audio>` | Весь звук сводит `scripts/mix.py` в один `assets/master.wav`; в странице один `<audio id="master">` |
| `duplicate_audio_track`, слот звука тянется до конца | У `<audio>` нет `data-duration`. Не плодить звуки в HTML, см. строку выше |
| Кадр целиком пустой (цвет бумаги) | Синтаксическая ошибка в скрипте страницы (например, реальный перевод строки внутри строки, собранной в `build.mjs`). `check` её не ловит: смотреть снимок |
| Кадр частично пустой, сверху красная плашка | Исключение в `PENCIL_RENDER`: текст ошибки печатает обработчик `hf-seek`, читать на снимке |
| Рука/голова не рисуется, нет ошибки | В `leverHead` помощник `M` принимает массив `[x, y]`, не два числа: иначе NaN и линия молча пропадает |
| `np.convolve` на 13 млн отсчётов висит | Скользящее среднее через `cumsum` (так в `mix.py`) |
| `taskkill /IM python.exe` запрещён | Убивает чужие процессы. Останавливать конкретную фоновую задачу по её id |
| Случайность разная при каждом рендере | Только `PE.hr(...)` с зерном, никакого `Math.random`; рисунок меняется 12 раз/с (`S.di`) |
| Звук разъехался с картинкой после правки длины | Пересобрать: `node build.mjs && python scripts/mix.py` |
| Удар не совпадает со словом | Слово задано в `build.mjs` (`IMPACT_WORD`), время берётся из `spec/words.json`; у первой сцены сдвиг +0.45 с (`LEAD`) |
