# Зомби: как делать повествовательную анимацию и что для неё использовать

Другие материалы в этой папке: [СРАВНЕНИЕ.md](СРАВНЕНИЕ.md) (чем отличаются версии и что такое «зомби-стиль»), `версия-1-кругляши/` (всё нарисовано своим кодом) и `версия-2-чб-на-риге/` (ч/б на риге из репозитория), у каждой свой README.

Памятка по формату, который получился в `slova_povestvovanie.mp4` (эпизод `SlovaStory`). Формат снят с ролика «Как пережить ЧУМУ?» (канал «Записки выжившего»). Цель: спокойный рассказ без резкости и лишних звуков. Чужие кадры и текст не используются, перенят только подход.

## 1. Правила формата

Они взяты из замеров референса (27,5 мин, первые 7 минут по кадрам, весь ролик по субтитрам).

| Что | Правило | Откуда |
|---|---|---|
| Картинка | Плоская графика без контуров и свечения. Приглушённая земляная палитра, фигуры в профиль, стоят на линии земли. | Кадры референса |
| Длина плана | В среднем 6 с (медиана 5,3 с), максимум до 25 с. У нас 4,7–6,3 с. | Замер: 66 границ за 7 мин |
| Переходы | Только растворение (0,5 с) и уход в чёрное. Ни вспышек, ни тряски, ни шторок. | Растворения у референса медленные, примерно 1–2 с (по контактному листу), у нас 0,5 с: при желании удлинить |
| Камера | Ровный дрейф без разгона, ±5–10 % масштаба за план. | Кадры референса |
| Персонажи | Почти не двигаются: дыхание, моргание, редкий жест. | Кадры референса |
| Текст на экране | Субтитров нет. Только плашка внизу слева (заголовок, красная черта, мелкая строка) и чёрный титр. | Кадры референса |
| Вставки | «Тетрадь в линейку» с виньеткой и рисующимся человечком, карта, стена предметов. | Кадры референса |
| Речь | 13,5 символа/с, 138 слов в минуту. | Замер по субтитрам |
| Звук | Голос, под ним почти тишина. | Спектрограмма первых 60 с: речь и небольшой фон в начале. Музыку и шумы по всему ролику не проверял |
| Рассказ | Зловещая деталь → название → «давай проведём эксперимент» → конкретный человек с именем → числа внутри истории. | Субтитры |

## 4. Как сделать такой ролик с нуля

### Шаг 1. Разобрать референс
```bash
yt-dlp -f "bv*[height<=720]+ba" --merge-output-format mp4 -o ref.mp4 "<ссылка>"
yt-dlp --skip-download --write-auto-subs --sub-langs ru --sub-format vtt -o sub "<ссылка>"
C:\Users\daatva\voice-clone\venv\Scripts\python.exe -I C:\Users\daatva\Desktop\video\зомби\скрипты\measure_ref.py ref.mp4 420 sub.ru.vtt
```
Скрипт печатает длину планов, границы и скорость речи. Контактные листы:
```bash
ffmpeg -i ref.mp4 -vf "fps=1/2,scale=384:-1,tile=5x5:padding=4" -t 50 -frames:v 1 open.png
```
Смотреть листы глазами: палитра, камера, как выглядят плашки.

### Шаг 2. Написать текст
Пять-шесть реплик, по одной мысли. Историю ведёт конкретный человек с именем. Числа внутри событий. Читать вслух: 13–14 символов в секунду.

### Шаг 3. Озвучить
Темп и шаги задают скорость и качество. Для этого формата `--speed 0.75 --nfe 64`.
```bash
cd C:\Users\daatva\voice-clone
venv\Scripts\python.exe -I C:\Users\daatva\Desktop\video\зомби\скрипты\story_voice.py
```
Скрипт делает по три дубля каждой реплики (seeds 1–3) в `voice-clone/out/story/`. Тексты реплик лежат в самом скрипте, в списке `LINES`.

Длина фразы в F5 считается по числу букв, поэтому короткие реплики выходят короче, чем нужно. Если реплика из одного слова звучит обрезанно, ставить темп ещё ниже или делать её частью длинной.

Проверка дублей:
```bash
python C:\Users\daatva\Desktop\video\зомби\скрипты\check_voice.py C:\Users\daatva\voice-clone\out\story
```
Скрипт распознаёт речь и сравнивает с текстом. Числа распознаются цифрами («16 тысяч»), так что 0,67–0,9 на репликах с числами это норма. Лучший дубль выбирать всё равно на слух.

### Шаг 4. Расставить кадры
Правится массив `SHOTS` в `index.tsx`:
```ts
{ C: S3, a: 235, b: 425, fadeIn: 15, fadeOut: 0 }
```
`a`/`b` — кадры начала и конца (30 fps), `fadeIn`/`fadeOut` — растворения в кадрах. Если соседний план начинается раньше, чем кончается предыдущий (`S4.a = 410 < S3.b = 425`), в этом окне идёт растворение.

Раскладка текущего ролика:

| Кадр | Время | Реплика |
|---|---|---|
| S1 ночная кухня | 0–5,0 с | 1 |
| S2 чёрный титр | 5,0–7,8 с | тишина |
| S3 тетрадь | 7,8–14,2 с | 2 |
| S4 двор | 13,7–18,3 с | 3 |
| S5 стена томов | 17,8–24,0 с | 4 |
| S6 рассвет | 23,5–28,8 с | 5 |

### Шаг 5. Собрать голосовую дорожку
Команда запускается из `voice-clone\out\story`. Реплики кладутся на нужные секунды через `adelay`, сводятся `amix`, выравниваются `loudnorm` до −14 LUFS:
```bash
ffmpeg -y -i l1_s1.wav -i l2_s1.wav -i l3_s1.wav -i l4_s1.wav -i l5_s1.wav \
  -filter_complex "[0]aresample=44100,adelay=500|500[a];[1]aresample=44100,adelay=8333|8333[b];[2]aresample=44100,adelay=14167|14167[c];[3]aresample=44100,adelay=18333|18333[d];[4]aresample=44100,adelay=24167|24167[e];[a][b][c][d][e]amix=inputs=5:normalize=0,apad,atrim=0:28.8333,loudnorm=I=-14:TP=-1.5:LRA=7,aresample=44100" \
  -ac 1 C:\Users\daatva\Desktop\video\what-if-studio\public\slova-story\voice.wav
```
Старты в миллисекундах: 500, 8333, 14167, 18333, 24167. Длина дорожки равна длине ролика: кадры / 30.

### Шаг 6. Нарисовать кадры
Каждый кадр это функция `(t, len)`, где `t` — время внутри плана в кадрах. Всё анимируется от `t`, без состояния.

Герой:
```tsx
<Man x={850} y={880} t={t} sit palm armF={[30, -54]} mouth="frown" />
```
Параметры `Man`: позиция `x`, `y` (ступни), масштаб `s`, направление `dir` (1 вправо, −1 влево), цвета (`ring` — капюшон, `top`, `legs`), `armF`/`armB` — куда тянется кисть относительно плеча, `mouth` (`shut`, `flat`, `frown`, `talk`, `o`), `look`, `sit`, `palm` (ладонь вместо кисти, прикрыть рот), `seed` (смещает дыхание и моргание у разных людей).

Остальное: `Cat`, `Chip` (плашка снизу слева), `LineMan` (человечек, который рисуется линией по прогрессу `p`), `cam(cx, cy, s)` и `drift(t, len, a, b)` для ровной камеры, `P` и `F` — палитра и шрифты.

Приёмы, которые сработали:
- фон можно собрать из прямоугольников и кругов, без текстур; свет это полупрозрачный многоугольник и градиент;
- у людей на дальнем плане разные `seed`, чтобы не дышали синхронно;
- плашка и камера: плашка стоит вне группы с камерой, чтобы не плыла;
- виньета и зерно накладываются один раз сверху на весь ролик в `Film`.

### Шаг 7. Проверить
Раскадровка, по одному кадру на план:
```bash
cd what-if-studio
npx remotion render src/index.ts SlovaStoryBoard out/story/b --sequence --image-format=png
ffmpeg -y -i out/story/b/element-%d.png -vf "scale=640:-1,tile=3x2:padding=6:color=white" -frames:v 1 out/story/board.png
```
Рендер:
```bash
npx remotion render src/index.ts SlovaStory out/story/slova_story.mp4
```
Контактный лист готового:
```bash
ffmpeg -y -i out/story/slova_story.mp4 -vf "fps=1/1.8,scale=480:-1,tile=4x4:padding=4:color=white" -frames:v 1 out/story/sheet.png
```

Что смотреть на листе:
- ничего не перекрывает плашку и лица;
- герой в каждом кадре узнаётся;
- в стыках растворений нет скачка;
- рука у рта читается как рука, а не как круг (это было исправлено через `palm`).

Замеры звука:
```bash
ffmpeg -i slova_story.mp4 -vn -af "ebur128=peak=true" -f null NUL
ffmpeg -i slova_story.mp4 -vn -af silencedetect=noise=-40dB:d=0.4 -f null NUL
```

## 5. Результаты текущего ролика

- 865 кадров, 28,9 с, 1920×1080, 30 fps.
- Звук: −15,5 LUFS, пик −4,5 дБ.
- Самый резкий скачок между соседними кадрами приходится на растворение, резких склеек нет.
- Распознавание подтвердило, что все слова произнесены.

## 6. Что не проверено и что слабо

- Голос на слух не слушал. Темп 0,75 выбран по расчёту длительностей, не по впечатлению.
- Персонажи двигаются очень мало, как у референса. Если ролик покажется мёртвым, добавлять жесты в `armF`/`look` по времени `t`.
- Лицензия референса не изучалась: чужое не использовано, но подход скопирован. Если канал пойдёт в монетизацию, держать сюжет и героев своими.
- Голос клонирован с друга, для публичного канала нужно его согласие.
- Ролик короткий и тестовый. Полную серию (5–25 минут) по формату референса не делал.
- Ничего не закоммичено.
