# Пилот 01 — «Помнишь, как будет»

Обновление героев от 02.11.2026: [актуальные различия лиц и одежды](../CHARACTER-STYLE.md), [сравнения до/после](identity-review.html), [промпты и проверки](spec/identity-review.json). Ревизия `distinct-v3` вводит короткие кудри и широкое лицо Кости, бирюзовую куртку в 25 лет, отдельную одежду взрослого Димки и прямое каре с отдельными чертами лица Лены. Пилот подключает исправленные изображения; ранее сохранённые MP4 ниже показывают старую внешность до повторного рендера.

Два тестовых монтажа одного хука. Герои согласованы пользователем 31.10.2026; восемь канонических PNG находятся в `assets/`. Полное ТЗ: [codex-pilot-01.md](../codex-pilot-01.md).

- [А — спокойный монтаж](renders/pilot-01-calm.mp4): прямые склейки, небольшие плавные наезды.
- [Б — динамичный монтаж](renders/pilot-01-dynamic.mp4): бумажные переходы вместо растворения и крупные планы волос Кости и лица Саши.

Оба файла: MP4 H.264/AAC, 1920×1080, 24 fps; движение иллюстраций с шагом 12 fps. Длительность 11,75 с. Начало соответствует `video-01-script-v5.md`: ты просыпаешься, в комнату заходит брат («Мелкий, вставай»), носка в кадре и в тексте больше нет. Прежняя версия с носком (21,25 с) лежит в `renders/old-sock/`.

Озвучка — edge-tts `ru-RU-DmitryNeural` (`scripts/voice_neural.py`), реплика Кости с повышенным тоном.

Текст даты и субтитры, движение целых иллюстраций, плёночная виньетка, зерно и переходы выполняются кодом. Музыка не добавлялась; мягкий шорох двери при входе брата синтезирован кодом. В исходных картинках нет даты и подписей. Файл `assets/shots/p0_sock.png` оставлен в проекте, но не используется.

Проект использует HyperFrames 0.8.221 и бумажные функции из `nauka-frames/engine/paper.js`. Исходники прочитаны без изменений; этот проект хранит свою копию помощника в `engine/paper.js`.

## Повторная сборка

Из этой папки, Windows + Python + Node.js:

```powershell
python -m pip install -r requirements.txt
python -X utf8 scripts/voice_neural.py
node build.mjs
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/render.ps1 -Variant calm
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/render.ps1 -Variant dynamic
python scripts/review.py
```

`voice_neural.py` ходит в edge-tts (нужен интернет); готовые MP3 с метками слов кэшируются в `assets/voice-neural/`. Устаревший SAPI-черновик `voice.py` не используется. Сборщик копирует системные Arial/Georgia. `render.ps1` локально подставляет FFmpeg из пакета `imageio-ffmpeg`, не меняя системный PATH навсегда. Для проверки нужен доступный `ffprobe`.

Предпросмотр: `npm run preview`; спокойный вариант — `index.html`, динамичный — `compositions/dynamic.html`. Время ведёт HyperFrames; скрипт не запускает собственный таймер и не управляет воспроизведением аудио вручную.

## Проверки и происхождение

- `generation-log.json` — исходные пробы и согласование листов.
- `generation-log-scenes.json` — фактические промты, вложения, итерации задников/сцен и выбранные исходники; генерация встроенным `image_gen`.
- `spec/timeline.json` — измеренные интервалы речи, словесные метки edge-tts и момент входа брата (`doorAt`); покадровое выравнивание фонем не выполнялось.
- `spec/render-review.json` — параметры реальных MP4 и результат полного декодирования.
- `renders/review-calm.jpg`, `renders/review-dynamic.jpg` — выборочные кадры из соответствующих реальных видео для проверки композиции, даты и субтитров.

Это тестовые версии для выбора темпа монтажа; финальный голос канала отдельно не утверждён.
