# Пилот 01 — «Помнишь, как будет»

Два тестовых монтажа одного хука. Герои согласованы пользователем 31.10.2026; восемь канонических PNG находятся в `assets/`. Полное ТЗ: [codex-pilot-01.md](../codex-pilot-01.md).

- [А — спокойный монтаж](renders/pilot-01-calm.mp4): прямые склейки, небольшие плавные наезды.
- [Б — динамичный монтаж](renders/pilot-01-dynamic.mp4): более резкое ускорение носка, бумажные переходы и крупные планы волос Кости и лица Саши.

Оба файла: MP4 H.264/AAC, 1920×1080, 24 fps; движение иллюстраций с шагом 12 fps. Длительность 21,25 с, включая финальную паузу. Измеренная аудиодорожка 21,223 с; предварительные 15–16 секунд не стали ограничением для текста.

Слова пилота не изменены. Черновая озвучка — русский системный голос Microsoft Irina Desktop (Windows SAPI), без ускорения; реплика Кости отличается высотой тона. Голос предназначен для проверки монтажа. Онлайн-озвучка не вернула звук, поэтому использован доступный локальный вариант.

Текст даты и субтитры, удаление зелёного фона носка, движение целых иллюстраций, плёночная виньетка, зерно и переходы выполняются кодом. Музыка не добавлялась; шорох/мягкий удар носка синтезированы кодом. В исходных картинках нет даты и подписей.

Проект использует HyperFrames 0.8.221 и бумажные функции из `nauka-frames/engine/paper.js`. Исходники прочитаны без изменений; этот проект хранит свою копию помощника в `engine/paper.js`.

## Повторная сборка

Из этой папки, Windows + Python + Node.js:

```powershell
python -m pip install -r requirements.txt
python scripts/voice.py
node build.mjs
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/render.ps1 -Variant calm
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/render.ps1 -Variant dynamic
python scripts/review.py
```

`voice.py` использует установленные русский голос SAPI и `System.Speech`; кэшированные WAV уже приложены. Для полного воспроизведения словесных меток требуется этот голос. Сборщик копирует системные Arial/Georgia. `render.ps1` локально подставляет FFmpeg из пакета `imageio-ffmpeg`, не меняя системный PATH навсегда. Для проверки нужен доступный `ffprobe`.

Предпросмотр: `npm run preview`; спокойный вариант — `index.html`, динамичный — `compositions/dynamic.html`. Время ведёт HyperFrames; скрипт не запускает собственный таймер и не управляет воспроизведением аудио вручную.

## Проверки и происхождение

- `generation-log.json` — исходные пробы и согласование листов.
- `generation-log-scenes.json` — фактические промты, вложения, итерации задников/сцен и выбранные исходники; генерация встроенным `image_gen`.
- `spec/timeline.json` — измеренные интервалы речи, 38 словесных меток и момент удара носка. Относительные метки SAPI приведены к длительности соответствующих WAV; покадровое выравнивание фонем не выполнялось.
- `spec/render-review.json` — параметры реальных MP4 и результат полного декодирования.
- `renders/review-calm.jpg`, `renders/review-dynamic.jpg` — выборочные кадры из соответствующих реальных видео для проверки композиции, даты и субтитров.

Это тестовые версии для выбора темпа монтажа; финальный голос канала отдельно не утверждён.
