# «Вдруг ты» — бумажный комплект

Готово 4 ноября 2026: шесть превью, три аватара, один баннер. [Открыть галерею](index.html), [скачать комплект](delivery.zip), [посмотреть общий лист](review/contact-sheet.jpg).

## Файлы

- `thumbnails/T1–T6.png` и `.jpg`: 1280×720, каждый файл меньше 2 МБ.
- `avatars/L1–L3.png`: 800×800; круглые варианты и проверки 98 px находятся в `review/`.
- `banner/B1-2560x1440.png` и `.jpg`: баннер с названием «ВДРУГ ТЫ». Центральная обрезка — `review/banner-center-1546x423.png`.
- `raw/`: исходные иллюстрации без типографики; принятые исходники включены в ZIP, отклонённый T6 оставлен только в проекте.
- `references/original-approved.png`: копия исходного эталона пользователя для переносимости комплекта.
- `prompts.md`, `prompts.json`, `generation-log.json`: полные фактические запросы, референсы и исправления.
- `export-review.json`: размеры, вес, надписи и границы текста.
- `previous-prompts/`: прежние два документа до перехода к бумажному стилю.

## Стиль и сборка

Основа — предоставленное пользователем превью с бумажным каштановолосым героем. Сохранены его лицо, возраст, волосы и оливковая футболка; добавлены оранжевые наушники. Бирюзовый фон, кремовые рваные листы и золотистый текст повторяются в комплекте. Прежняя манга не используется. Ничего в существующих файлах другого канала не заменено.

Генерация выполнена встроенным `image_gen`; буквы, цифры, список и эмблема добавлены Pillow. Повторная сборка из исходников: `python channels/vdrug-ty/branding-paper-2026-11-04/scripts/finish_pack.py` из корня репозитория. Нужны Python, Pillow и системные Arial / Arial Narrow Bold из Windows. Скрипт не обращается к API и не перегенерирует изображения.

ZIP содержит финальные изображения, принятые исходники `raw/`, эталон, галерею, уменьшенные проверки, промпты, журналы и скрипт. Из распакованного ZIP можно пересобрать файлы командой `python scripts/finish_pack.py` из папки комплекта при наличии указанных зависимостей и шрифтов.

Проверены декодирование файлов, размеры, вес превью, границы текста; выполнен визуальный просмотр иллюстраций, общего листа, круглых аватаров и центральной обрезки баннера. Отдельно исправлены T6 (генератор добавил героя) и высота героя на баннере. Подписи поставлены на контрастные плашки.

Данных CTR нет, победитель Test & Compare не определён. Для старта можно взять T2 и L2; это редакционный выбор, а не измеренный результат. Для первого ролика сравнивать T1/T2/T3 или T2/T3/T6. T4/T5 не являются альтернативами для ролика про 2010 год.
