# «Что, если все твои слова за жизнь прозвучат разом?» — цветной тест, медленная версия

Тестовый 15-секундный ролик в формате «ТО 420» (абсурдное «что, если» с подсчётом, голос клонирован с друга), собранный на движке what-if-animation. Эта папка — то, что отдаётся на ручную доработку.

## Что лежит в папке

| Файл | Что это |
|---|---|
| `slova_cvet_medlenno.mp4` | **Основная версия.** 21,4 с, 1920×1080, 30 fps. Спокойный темп, паузы между репликами. |
| `slova_cvet_bystro_v1.mp4` | Первая быстрая версия (15,0 с), для сравнения. |
| `голос/replika_1…5_*.wav` | Пять реплик отдельными файлами, без обработки. Из них можно собрать другой ритм. |
| `голос/golos_vse_medlenno.wav` | Готовая голосовая дорожка медленной версии (21,3 с, −14 LUFS, пик −1,5 дБ). |
| `кадры/` | Контактные листы обеих версий. |
| `timeline_medlenno.json` | Монтаж медленной версии: какой кадр с какого по какой фрейм. |

Исходники лежат в `what-if-studio/` (рядом с этой папкой, в корне проекта). Ничего не закоммичено.

## Что поменялось между быстрой и медленной версией

Кадры и голос те же. Изменён только монтаж.

- Длина 15,0 с → 21,4 с (примерно ×1,4).
- Каждый кадр растянут в 1,1–1,8 раза: движение камеры, появление слов и чисел идут медленнее (больше всего растянуты S1, S3, S7 и S9).
- Между репликами паузы 1,8–2,5 с (было ровно 1,0 с). В паузах работает картинка: считается калькулятор, растёт счётчик, собирается стопка книг.
- Голос начинается через 0,5 с после старта, а не с нулевого кадра. Ролик заканчивается паузой 2,4 с после последней реплики.
- Громкость выровнена до −14 LUFS (в быстрой версии выровнена не была).

## Как это делалось

1. **Разведка ниши.** Разобрал «What If» на стикменах и канал Jeremy Bearimy, историю формата и инструменты. Проверил репозитории: подошёл только `kelano86/what-if-animation` (MIT). Подробности в `research/`.
2. **Первые попытки на своём SVG** (`my-video/src/Test420/`). Первая версия: толстая ровная линия, стикмены, пусто. Вторая: тонкая дрожащая линия, герои-«капли» с лицами, 9 кадров, формат 2,39:1. Картинка осталась тонкой и скомканной, поэтому ушёл от самодельной рисовалки к движку с готовым ригом.
3. **Движок what-if-animation** (`what-if-studio/`). Герой рисуется одной функцией-ригом, поэтому не «плывёт». Каждый кадр — чистая функция от своих часов `t`, монтаж — это просто таймлайн из отрезков. Под нас переделано:
   - шрифты на кириллицу (Montserrat, Roboto Mono, Neucha), чтобы титры и числа читались по-русски;
   - акцент титра сделан под кириллицу (регулярка с юникодом);
   - убраны жёсткие цвета в риге (красные наушники друга, голубая слеза), чтобы палитра была цельной.
4. **Эпизод `Slova`** (`src/episodes/slova/`): девять кадров с камерой, героем, комнатами (кухня, кабинет, крыша), схемами и титром. Это и есть цветная версия.
5. **Голос.** Клон голоса друга на F5-TTS (`C:\Users\daatva\voice-clone\say.py`, голос `friend`). Пять реплик генерируются локально, без API. Затем `ffmpeg` расставляет их по времени (`adelay`) и сводит в одну дорожку (`amix`), `loudnorm` выравнивает до −14 LUFS.
6. **Медленная версия.** Эпизод `SlovaSlow` (`src/episodes/slova-slow/`) берёт те же кадры из `slova`, но с новым `timeline.json`. Растянуть кадр можно одним числом: у отрезка длиннее диапазон кадров `a…b`, а часы кадра идут `t0…t1` как раньше. Голосовая дорожка пересобрана с паузами.
7. **Проверка.** Рендер `npx remotion render`, контактные листы кадров, громкость и тишина по `volumedetect` и `silencedetect`. Ролик целиком я не смотрел и не слушал: звук проверен только измерениями.

## Как пересобрать

Из папки `what-if-studio/`:

```bash
# кадры и таймлайн: src/episodes/slova-slow/timeline.json  (segments: a, b — кадры; t0, t1 — часы кадра)
npx remotion render src/index.ts SlovaSlow out/slow/slova_slow.mp4
```

Голосовая дорожка (старты реплик в миллисекундах: 533, 4867, 7300, 12333, 17067), реплики лежат в `my-video/public/test420/`:

```bash
ffmpeg -y -i t420_001.wav -i t420_002.wav -i t420_003.wav -i t420_004.wav -i t420_005.wav \
  -filter_complex "[0]aresample=44100,adelay=533|533[a];[1]aresample=44100,adelay=4867|4867[b];[2]aresample=44100,adelay=7300|7300[c];[3]aresample=44100,adelay=12333|12333[d];[4]aresample=44100,adelay=17067|17067[e];[a][b][c][d][e]amix=inputs=5:normalize=0,apad,atrim=0:21.3333,loudnorm=I=-14:TP=-1.5:LRA=7,aresample=44100" \
  -ac 1 voice.wav
```

Новая реплика голосом друга: `venv\Scripts\python.exe say.py -t "Текст" -o out\x.wav` (в папке `voice-clone`).

## Что подправить руками

- **Паузы.** Если 2 с между репликами кажутся мёртвыми, сдвиньте реплики 2–5 ближе (старты выше) и укоротите соответствующие отрезки в `timeline_medlenno.json`.
- **«Считаем.»** Реплика 0,4 с: слишком короткая, может быть обрезана. Стоит перегенерировать (`--seed`, `--speed`) и послушать.
- **Пустая сетка.** В начале S5 и S9 схема строится с пустого поля примерно 0,7 с. Можно начать с рисующейся иконки или сократить кадр.
- **Звук.** Кроме голоса нет ничего: ни шумов, ни музыки. Библиотека звуков what-if-animation сделана на бесплатном плане ElevenLabs (некоммерческая), для монетизации не подходит. Вариант: синтезированные звуки из `papercut-explainer` (в README заявлено «без файлов под лицензией», на слух не проверял).
- **Герой.** Pip и комнаты принадлежат репозиторию. Для канала нужен свой герой, иначе узнаваемость будет чужой.
- **Субтитры.** В цветной версии отдельных субтитров нет: слова летят по кадру и в титрах.

# Версия «повествование» (`slova_povestvovanie.mp4`, 28,9 с)

Та же тема, переделанная по разбору ролика «Как пережить ЧУМУ?» (канал «Записки выжившего»). Чужие кадры и текст не использованы, перенят только подход.

| Что замерено в ролике | Как сделано у нас |

| Плоская графика без контуров и свечения, приглушённая земляная палитра, фигуры в профиль на линии земли | Своя фигура и фоны в `what-if-studio/src/flat/kit.tsx`, герой в худи остался узнаваемым |
| План в среднем 6,3 с, медиана 5,3 с | Планы по 4,7–6,3 с |
| Растворения и уходы в чёрное, резких склеек нет | Растворения 0,5 с, чёрный титр; вспышек и тряски нет |

| Субтитров нет, только плашка снизу слева и чёрный титр | Так же |
