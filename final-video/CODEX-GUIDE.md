# Финальный гайд для Codex: как собрать ролик от темы до файла

Версия от 10.11.2026. Продукт: вертикальный чёрно-белый ролик на 60 секунд. Один закон или факт, история на бытовом примере, голос-клон, контурные человечки, заголовок в каждом кадре. Рисует код (SVG в Remotion), внешних картинок нет.

Где что лежит: [ROADMAP.md](ROADMAP.md). Подробности и замеры: [README.md](README.md). Если гайд и README расходятся, верь более новому утверждению и сообщи о расхождении.

10.11.2026 на этой машине проверены `script_check.py`, `gen_timing.py`, раскадровка, рендер отрезка через `--frames` и проверка кадров и громкости. Полную озвучку и полный рендер по этому гайду не запускали: они работали в предыдущих сессиях. Все пути от корня `C:\Users\daatva\Desktop\video`, голос лежит в `C:\Users\daatva\voice-clone`. Оболочка PowerShell 5.1: `&&` не работает.

Обозначения: `тема` — латинский слаг (`kobry60`), `Тема` — то же с большой буквы для id (`Kobry60Bw`).

## 1. С чего начать

1. Прочитай этот файл целиком.
2. Посмотри эталон: `final-video/ringelman60/render/ringelman60.mp4` или его кадры `render/board.png`.
3. Определи режим:
   - **Полный:** есть видеокарта и `voice-clone`. Делаешь всё.
   - **Только картинка:** голос уже дан (`best.wav`, `best_words.json`, `plain.txt`), модели нет. Начинай с шага 4, текст и звук не трогай.
4. Если тема не задана, бери следующую без озвучки из [SCRIPTS-60.md](SCRIPTS-60.md). Там 13 готовых текстов с источниками, названиями и тегами.

**Править только живой код:** `what-if-studio/` и `voice-clone/`. Папки `final-video/studio-snapshot/`, `*/episode/`, `чистовик/` и `codex-тест/` это копии: рендер их не видит.

Работай экономно: ищи нужное через `rg`, длинные логи пиши в файл, долгий рендер не опрашивай каждые несколько секунд. Обратимые мелочи решай сам. Спрашивай только то, что меняет результат, одним вопросом с вариантами. Отвечай по-русски.

## 2. Формат

| Параметр | Значение |
|---|---|
| Кадр | 1080×1920, 30 fps, только чёрное и белое |
| Длина | 60 с, в рендере 52–60 с |
| Текст | 150–165 слов, фразы 3–9 слов |
| Планы | 22–28, в среднем 2–2,5 с |
| Склейки | только жёсткие, в паузе, за 0,08 с до первого слова фразы |
| Голос | клон F5-TTS, −15 LUFS |
| Паузы | 0,26 с после точки, 0,36 с после вопроса |
| Звук | только голос и тихий фон комнаты |
| Конец | уход в белое с концом последнего слова, после него не больше 0,5 с |

Паузы удлинили озвучку. На 60 с с новыми паузами полный ролик ещё не собирали: если голос вышел длиннее 60 с, сокращай текст, а не ускоряй голос.

## 3. Решения пользователя: не менять без спроса

- **Ролик всегда 60 секунд.**
- **Сначала тест примерно на 15 секунд.** Полный рендер только после одобрения теста, если пользователь прямо не разрешил иначе.
- **Никаких придуманных звуков.** Без SFX и музыки: пользователь сказал убрать их совсем. Живые звуки только настоящими записями и только после разрешения на скачивание.
- **Паузы между фразами нужны.** Старая пометка «без пауз» относилась к длинным провалам режима `--whole`.
- **Мат 4–6 раз на ролик**, только в голосе и там, где он усиливает эмоцию: хук, удивление, абсурд, обвинение зрителю, финал. На экране мата нет.
- **Озвучка только через `voiceover.py`.** Одна озвучка на видеокарту за раз.
- **Свои темы, текст и рисунок.** Сцены, тексты и шутки чужих роликов не копировать, голос и юмор «420» не повторять.
- **Факты сверять** по первоисточнику или двум обзорам до записи голоса. Вымышленных героев и их суммы отмечать как вымысел, непроверенное `[проверить]`.
- **Публикация только по прямой просьбе.** Голос клонирован с друга: перед публичным выпуском нужно его согласие.
- **Коммиты и push только по просьбе.**

## 4. Конвейер

Два обязательных стопа: после текста (шаг 2) и после теста (шаг 8).

### Шаг 1. Тема и факты

Один закон, исследование или история с именами, годами, числами. Новую тему проверяй на спрос по [README, раздел 0](README.md): доказанный интерес у другого автора, но этой темы у него нет. Банки идей: `TOPICS-FROM-HITS.md`, `scripts/IDEAS-next5.md`, `research/topics-instagram.md`, `research/larkin-life/IDEAS-top3.md`.

### Шаг 2. Текст

| Блок | Что делает | Время |
|---|---|---|
| Хук | обвинение зрителю или парадокс, его слово вернётся в финале | 0–5 с |
| Имя и дата | закон или исследователь, год | 5–12 с |
| История и доказательство | один герой, поворот, одно число | 12–38 с |
| «Вот ещё» | 1–2 примера, каждый короче предыдущего | 38–46 с |
| Совет | что сделать завтра | 46–55 с |
| Закольцовка | слово из хука с новым смыслом | последние 5 с |

Первое слово лучше «ты», «твой» или неожиданный предмет. Без «привет» и «вы знали». Масштаб переводи в знакомое, абстракцию в быт. Числа можно цифрами, конвейер прочитает их словами.

Сохрани текст в `C:\Users\daatva\voice-clone\texts\тема.txt` и `final-video\тема\script.txt`. Проверка:

```powershell
python "C:\Users\daatva\.claude\skills\humanizer-ru-novella\scripts\script_check.py" final-video\тема\script.txt --minutes 1 --wpm 162
```

FAIL чини, WARN смотри глазами. **Стоп:** покажи текст и источники, дождись одобрения. Для текстов из `SCRIPTS-60.md` тоже подтверди выбор темы.

### Шаг 3. Озвучка

```powershell
cd C:\Users\daatva\voice-clone
venv\Scripts\python.exe voiceover.py texts\тема.txt --name тема --min-words 1 --short-speed 0.85
```

- Идёт долго, на тексте «Я просто пошутил» около 35 минут. Запускай в фоне, лог пиши в файл.
- Проверочный прогон `--nfe 32`, финал на 64 (по умолчанию). Кэш `out\_cache` делает перезапуск почти бесплатным.
- Для одной плохой короткой фразы: `--slow "пл+атье=0.75"`.
- Низкий гул перед гласной («пуп») убирается сам, порог `--onset-min`.

В `out\тема\` появятся `best.wav`, `best_words.json`, `plain.txt`, `marked.txt`, `disputed.txt`, `report.json`.

Проверь `report.json` по списку потерянных слов, а не по числу `match`. Слова из `disputed.txt` должен послушать человек: распознавание ударения не слышит. Неверное слово добавь в `stress_dict.txt` (`шн+обелевка`, каждая форма на своей строке) и запусти заново. Если пользователь не слушал голос, напиши это в отчёте.

Положи голос в проект и в папку ролика:

```powershell
Copy-Item C:\Users\daatva\voice-clone\out\тема\best.wav, C:\Users\daatva\voice-clone\out\тема\best_words.json, C:\Users\daatva\voice-clone\out\тема\plain.txt, C:\Users\daatva\voice-clone\out\тема\marked.txt, C:\Users\daatva\voice-clone\out\тема\disputed.txt, C:\Users\daatva\voice-clone\out\тема\report.json final-video\тема\voice\
```

### Шаг 4. Планы и тайминги

Создай `final-video\тема\plans.json`: на каждый план id, первые слова его фразы и слова-события внутри.

```json
[["p1","да я пошутил",{"quote":"пошутил","conv":"удобная"}],
 ["p2","сказал гадость",{"bad":"гадость","tag":"шутка"}]]
```

Слова бери из `plain.txt`: там числа уже написаны словами. Id должны быть допустимыми именами JS. Новая мысль это новый план.

```powershell
python final-video\tools\gen_timing.py --spec final-video\тема\plans.json --voice C:\Users\daatva\voice-clone\out\тема --out what-if-studio\src\episodes\тема-bw\timing.ts --tail 12 --fade 15 --lead 0.08
```

Папка эпизода должна уже существовать (шаг 5). Скрипт пишет `TOTAL`, `VOICE_END`, `FADE`, `PLANS` и `T.p1.quote` (кадр слова от начала плана). Кракозябры в консоли безвредны. Если нужна плашка «ДАЛЬШЕ», используй `--tail 54 --fade 10`.

### Шаг 5. Эпизод

```powershell
New-Item -ItemType Directory -Force what-if-studio\src\episodes\тема-bw
Copy-Item what-if-studio\src\episodes\yaposhutil-bw\index.tsx what-if-studio\src\episodes\тема-bw\
```

В `index.tsx` замени список `COMPONENTS`, путь `staticFile('тема/voice.wav')`, имя экспорта и `id`:

```tsx
export const темаBw = { id: 'ТемаBw', total: TOTAL, shotCount: SHOTS.length, width: W, height: H, Main, Board };
```

В `what-if-studio\src\episodes\index.ts` добавь import и элемент массива `EPISODES`. `Root.tsx` сам создаст две композиции: `ТемаBw` (ролик) и `ТемаBwBoard` (раскадровка). Удалять `piter-bw/shots.tsx` и `abilin-bw/shots.tsx` нельзя: от них зависят другие эпизоды.

### Шаг 6. Сцены

`shots.tsx`: одна сцена на план, время внутри сцены отсчитывается от её начала.

```tsx
import React from 'react';
import { useCurrentFrame } from 'remotion';
import { G, Ground, Head, Man, Sheet, Stamp } from '../piter-bw/shots';
import { Backdrop } from '../../lines/env';
import { T } from './timing';

export const S1: React.FC = () => {
  const t = useCurrentFrame();
  return (
    <Sheet hit={T.p1.conv}>
      <Head lines={['САМАЯ УДОБНАЯ', 'ФРАЗА В МИРЕ']} t={t} />
      <Backdrop kind="street" v={0} t={t} />
      <Ground />
      <Man x={330} y={G} s={1.75} mouth="grin" eyes="dots" hair="tuft" seed={7} bob />
      <Stamp x={700} y={1010} text="УДОБНО" t={t} at={T.p1.conv} size={110} />
    </Sheet>
  );
};
```

Порядок слоёв: `Head`, задник, `Ground`, герои, пузыри, штампы.

| Что | Откуда |
|---|---|
| `Sheet, Tx, Head, Draw, Pop, Ground, Stamp, Man, Specs, Tash, Car, Confetti, Check, W, H, G` | `episodes/piter-bw/shots` |
| `Clock, Cloud, INK, PAPER, hand, rnd` | `lines/kit` |
| `Backdrop kind="street\|yard\|office" v={0..3} t={t}`, здания, деревья, улица | `lines/env` |
| `Place kind="openspace\|meeting\|home-desk\|cafe\|gym\|kitchen" v={0..3} t={t}` | `lines/places` |
| Пузырь `Bub`, стол `Desk`, героиня `Lera` | локально в `yaposhutil-bw/shots.tsx`, копировать оттуда |

Параметры `Man`: `x, y, s, flip, mouth, eyes, brow, hair, la, ra, seed, bob`. Масштаб главного героя 1,5–1,75, толпы 0,75–0,9.

Правила кадра:

- Заголовок 2–6 слов сжимает мысль, а не повторяет голос. Он занимает верх до y≈460.
- Герой слева (x≈330) или справа, пузырь на y 700–900, штамп около y 1010.
- Нижние 300–350 px закрывает интерфейс Reels: там только земля и штриховка.
- Каждый элемент появляется на своём слове через `T.план.событие`.
- В каждом кадре что-то движется. На ролик нужны минимум одна толпа и одна шутка в рисунке.
- Соседние сцены не должны повторять задник: чередуй `kind` и `v`.
- Подпись не клади рядом с осью графика. Штамп не закрывает героя, его ширина: `букв × размер × 0,56 + 70`.

Для теста достаточно сцен на первые 6–8 планов: `SHOTS` строится по `COMPONENTS`, поэтому остальные можно дописать позже.

### Шаг 7. Раскадровка

Команды из папки `what-if-studio`:

```powershell
npx remotion render src/index.ts ТемаBwBoard out/тема/b --sequence --image-format=png
ffmpeg -v error -y -framerate 1 -start_number 0 -i out\тема\b\element-%02d.png -vf "scale=240:427,tile=7x4" -frames:v 1 out\тема\board.png
```

Если кадров меньше 10, шаблон `element-%d.png`. Открой лист и исправь наложения, пустые кадры, вылезающий текст. Смотри своими глазами, а не только по логу.

### Шаг 8. Тест 15 секунд

Возьми из `PLANS` конец плана около кадра 450:

```powershell
npx remotion render src/index.ts ТемаBw out/тема/test15.mp4 --frames=0-КОНЕЦ_МИНУС_1
```

Склейка попадает в паузу, поэтому звук не оборвётся посреди слова. Проверь кадры на ключевых словах и громкость (шаг 9). **Стоп:** отправь тест пользователю и дождись одобрения.

### Шаг 9. Полный ролик и проверка

Допиши оставшиеся сцены и отрендери:

```powershell
npx remotion render src/index.ts ТемаBw out/тема/тема.mp4
ffmpeg -v error -y -i out\тема\тема.mp4 -vf "select='eq(n\,80)+eq(n\,125)',scale=360:640,tile=2x1" -frames:v 1 -fps_mode passthrough out\тема\frames.png
ffmpeg -hide_banner -i out\тема\тема.mp4 -af loudnorm=I=-15:print_format=summary -vn -f null NUL
ffmpeg -hide_banner -ss ВРЕМЯ_ПОСЛЕ_СЛОВА -i out\тема\тема.mp4 -af volumedetect -vn -f null NUL
```

Вторая команда показывает кадры на словах: подставь свои номера кадров. Третья даёт громкость, цель около −15 LUFS. Четвёртая подтверждает, что после последнего слова тихо.

### Шаг 10. Выдача и архив

В `final-video\тема\` должны лежать `script.txt`, `plans.json`, `voice\`, `episode\` (копия из `what-if-studio`), `render\`, `DESCRIPTION.md`. Готовый файл скопируй в `для Ютуба\` или `для Инстаграма\` с именем `тема_60s.mp4`.

`DESCRIPTION.md` (образец `ya-poshutil/DESCRIPTION.md`): заголовок-хук, зацепка на комментарии, абзац с цифрами и источником, честная оговорка, что вымышлено. Instagram 5 широких тегов, YouTube Shorts 3–5, `#shorts` последним. Узких тегов с названием закона не ставить. Ссылку на телеграм в образцах подставлять свою или убирать.

## 5. Если что-то сломалось

| Симптом | Что делать |
|---|---|
| `ffmpeg: No such file` на `element-%d.png` | кадров 10 и больше, нужен `%02d` |
| `не найден план` в `gen_timing.py` | первые слова не совпали с `plain.txt` или порядок планов нарушен |
| `нет слова` в `gen_timing.py` | слово-событие стоит вне диапазона своего плана |
| `жду GPU` | другая озвучка идёт, это нормально; параллельно не запускать |
| `voiceover.py --help` падает | кодировка консоли; задай `$env:PYTHONIOENCODING='utf-8'` |
| `NativeCommandError` в PowerShell | предупреждение Python в stderr; смотри, появился ли `best.wav` |
| Дубли готовы, `best.wav` нет | [README, раздел 5](README.md), «Если конвейер упал после дублей» |
| Обрывки слов в конце фраз | не повышать затухание; `--tries`, `--short-speed 0.85`, `--slow` |
| `-vsync` не работает | `-fps_mode passthrough` |
| `tsc` ругается на старые эпизоды | это не твои ошибки, рендер идёт |
| Кириллица ломается в выводе | пиши результат в файл UTF-8 |
| Сменили образец голоса или модель | очисти `voice-clone\out\_cache` вручную, ключ кэша их не видит |

## 6. Чек-лист перед сдачей

- [ ] Текст одобрен, факты сверены, вымысел отмечен
- [ ] 150–165 слов, `script_check.py` без FAIL, мат 4–6 раз, на экране его нет
- [ ] Хук за 3–5 с, финал возвращает слово из хука
- [ ] Только чёрное и белое, заголовок 2–6 слов в каждом кадре
- [ ] В нижних 300–350 px ничего важного, текст не вылезает из пузырей
- [ ] Есть толпа и шутка в рисунке, в каждом кадре есть движение
- [ ] Ни одного SFX и музыки
- [ ] В `report.json` нет потерянных слов, `disputed.txt` разобран или передан на слух
- [ ] Склейки в паузах, голос не обрезан, после последнего слова не больше 0,5 с
- [ ] Около −15 LUFS, длина 52–60 с
- [ ] Тест на 15 с одобрен до полного рендера
- [ ] Заполнена папка в `final-video\тема\`, есть описание и теги

## 7. Как отчитаться

Коротко и по-русски: что получилось и где файл, чем проверено, что не проверено. Отдельно перечисли места, которые может решить только человек: ударения на слух, спорные факты, согласие на голос.
