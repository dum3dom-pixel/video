# Давалка: локальная озвучка клоном голоса

Памятка: как поставить и пользоваться. Текст → готовый `.wav` с таймингами слов, всё на своей видеокарте, без платных сервисов.

Версии и команды ниже сняты с рабочей машины (Windows 11, Python 3.10.11, RTX 4070 Ti SUPER 16 ГБ, драйвер 621.01, ffmpeg 9.0.2). Чистую установку по этой памятке с нуля мы не прогоняли. Если что-то не встанет, смотри раздел «Если не работает».

---

## 1. Что понадобится

- **Windows.** Скрипт использует `msvcrt` для замка GPU, на Linux и Mac без правки не запустится.
- **Видеокарта NVIDIA.** У нас 16 ГБ видеопамяти. Минимум не проверяли.
- **Python 3.10** (у нас 3.10.11). Другие версии не проверяли.
- **ffmpeg** в PATH. Проверка: `ffmpeg -version`.
- **Место на диске:** модель голоса 1,3 ГБ, плюс при первом запуске докачиваются Whisper `medium` (около 1,5 ГБ), модели ударений и вокодер. Закладывай 8–10 ГБ с запасом.
- **Образец голоса** (раздел 3) и **согласие** человека, чей голос клонируешь. Голос чужого человека без его ведома не используем.

## 2. Установка

Папка может быть любой. Дальше она называется `voice-clone`.

### 2.1. Файлы

В `voice-clone` кладём три файла:

- `voiceover.py`: конвейер;
- `text_tools.py`: текстовая часть и проверка;
- `stress_dict.txt`: словарь ударений.

Копии лежат в `final-video\tools\voice-pipeline\`. Скрипты сами ищут всё рядом с собой, пути менять не надо.

В `stress_dict.txt` сейчас слова из наших роликов (шнобелевка, абилин и так далее, есть мат). Можно очистить файл и оставить только строку-комментарий.

### 2.2. Окружение для голоса (`venv`)

PowerShell, в папке `voice-clone`:

```powershell
py -3.10 -m venv venv
venv\Scripts\python.exe -m pip install --upgrade pip
venv\Scripts\python.exe -m pip install torch==2.6.0 torchaudio==2.6.0 --index-url https://download.pytorch.org/whl/cu124
venv\Scripts\python.exe -m pip install f5-tts==1.1.22 librosa==0.11.0 soundfile numpy==1.26.4
```

Torch ставим первым и обязательно с `cu124`, иначе поставится версия без видеокарты. Проверка:

```powershell
venv\Scripts\python.exe -c "import torch; print(torch.__version__, torch.cuda.is_available())"
```

Должно вывести `2.6.0+cu124 True`. Если `False`, драйвер NVIDIA старый или torch поставился не тот.

### 2.3. Окружение для текста (`venv-text`)

Оно отдельное: иначе зависимости ударений и распознавания ломают F5.

```powershell
py -3.10 -m venv venv-text
venv-text\Scripts\python.exe -m pip install --upgrade pip
venv-text\Scripts\python.exe -m pip install faster-whisper==1.2.1 silero-stress==1.5 ruaccent==1.5.8.3 rutextnorm==2.1.0 onnxruntime
```

Имя папки `venv-text` менять нельзя, скрипт ищет интерпретатор по этому пути. Сами модели (silero, RUAccent, Whisper) скачаются при первом запуске.

### 2.4. Модель голоса

Модель: Hugging Face, репозиторий `Misha24-10/F5-TTS_RUSSIAN`. Нужны два файла:

- `F5TTS_v1_Base_v4_winter/model_212000.safetensors` (1,3 ГБ);
- `F5TTS_v1_Base/vocab.txt` (14 КБ).

Положить строго так (структуру папок скрипт ждёт именно такую):

```
voice-clone\model\F5TTS_v1_Base_v4_winter\model_212000.safetensors
voice-clone\model\F5TTS_v1_Base\vocab.txt
```

Скачать можно руками со страницы файлов репозитория или командой:

```powershell
venv\Scripts\python.exe -m pip install huggingface_hub
venv\Scripts\python.exe -c "from huggingface_hub import hf_hub_download as d; d('Misha24-10/F5-TTS_RUSSIAN','F5TTS_v1_Base_v4_winter/model_212000.safetensors',local_dir='model'); d('Misha24-10/F5-TTS_RUSSIAN','F5TTS_v1_Base/vocab.txt',local_dir='model')"
```

Вокодер (Vocos) F5 докачает сам при первой озвучке.

## 3. Образец голоса

Качество клона почти целиком зависит от образца. Положи в `voice-clone\voices\ИМЯ\` два файла:

- `ref.wav`: чистая речь **10–12 секунд**, без музыки, шума и эха. Говорить в той интонации, в которой хочешь слышать озвучку (у нас ироничная, живая). У нас образец 11,7 с, 24 кГц.
- `ref.txt`: **точная** расшифровка этого отрывка слово в слово, с пунктуацией. Ошибка в расшифровке портит весь клон.

Необязательно, но полезно: `ref_marked.txt`. Это та же расшифровка, но с ударениями (`+` перед ударной гласной: `гер+ой`). В нашем тесте дубли с размеченным образцом распознавались чище. Если файла нет, скрипт возьмёт `ref.txt`.

Папка по умолчанию называется `friend`. Для своего голоса назови папку как хочешь и передавай `--voice ИМЯ`.

Потолок живости задаёт образец: один отрывок в одной интонации даёт речь примерно в одной интонации.

## 4. Первый запуск

1. Создай папку `texts` и положи туда `test.txt` с одним-двумя абзацами. Числа можно писать цифрами (`69-й`, `30 000`), конвейер переведёт их в слова.
2. Сначала только подготовка текста (быстро, без озвучки):

```powershell
venv\Scripts\python.exe voiceover.py texts\test.txt --name test --voice ИМЯ --dry
```

   В `out\test\` появятся `plain.txt` (числа словами), `marked.txt` (с ударениями) и `disputed.txt` (слова, где два алгоритма разошлись).
3. Полная озвучка:

```powershell
venv\Scripts\python.exe voiceover.py texts\test.txt --name test --voice ИМЯ
```

   Первый запуск долгий: докачиваются модели. Дальше идёт быстрее, около 2 с на фразу плюс повторные дубли.
4. Всегда начинай с короткого куска на 15 секунд. Полный ролик только когда голос и ударения устроили.

Результат в `out\test\`:

| Файл | Что это |
| --- | --- |
| `best.wav` | лучший дубль, −15 LUFS, 48 кГц |
| `best_words.json` | время каждого слова (для синхронизации картинки и титров) |
| `marked.txt` | текст с ударениями |
| `disputed.txt` | спорные ударения, их надо послушать |
| `report.json` | длительность, совпадение с текстом (`match`), паузы (`gaps`), расхождения (`diff`) |

## 5. Что делает конвейер

1. **Числа словами** (`rutextnorm`).
2. **Ударения:** основной алгоритм silero-stress, поверх него твои правки из `stress_dict.txt`. RUAccent даёт второе мнение, расхождения идут в `disputed.txt`.
3. **Генерация.** Текст режется на предложения (вставки до 4 слов приклеиваются к предыдущему). Каждое предложение генерируется отдельно, скорость 1,0.
4. **Борьба с обрывом слов.** F5 иногда режет последнее слово. Для каждого предложения пробуется до 10 сидов, берётся первый, где звук в конце затухает не меньше чем на 18 дБ. Если такого нет, берётся самый мягкий. Между предложениями стык 0,06 с.
5. **Три дубля** всего текста (`--takes 3`).
6. **Сверка:** Whisper расшифровывает каждый дубль и сравнивает с текстом. Лучший выбирается по совпадению и штрафу за паузы длиннее 0,6 с.
7. **Громкость** лучшего дубля до −15 LUFS. Компрессии и эквалайзера нет.

Готовые генерации кешируются в `out\_cache`: перезапуск после правки одного слова почти бесплатный.

## 6. Рабочий цикл с ударениями

Автоматика ударений не слышит, поэтому финальная проверка только на слух.

1. Запусти озвучку и **послушай `best.wav` целиком**.
2. Открой `disputed.txt`: там слова, где silero и RUAccent не сошлись. Проверь их на слух.
3. Неверное слово добавь в `stress_dict.txt`: слово с `+` перед ударной гласной, **по одному на строку**, каждую форму отдельно:

```
шн+обелевку
шн+обелевка
вс+е
```

   Всё, что после `#`, комментарий.
4. Запусти озвучку заново: кеш пересчитает только изменившиеся предложения.

Известный случай: «все» silero читает как «всё», лечится строкой `вс+е`.

## 7. Параметры

| Флаг | Что делает | По умолчанию |
| --- | --- | --- |
| `--name` | имя папки результата (`out\NAME`) | обязателен |
| `--voice` | папка образца в `voices\` | `friend` |
| `--takes` | сколько дублей всего текста | 3 |
| `--speed` | скорость | 1,0 |
| `--nfe` | число шагов генерации | 64 |
| `--min-words` | предложения не длиннее N слов приклеиваются к предыдущему, 0 = не клеить | 4 |
| `--dry` | только подготовить текст | выкл. |
| `--whole` | старый режим: весь текст одним проходом, скорость 0,9 | выкл. |

Скорость выше 1,08 теряет слова, а 0,9 растягивает звуки, поэтому оставили 1,0. Режим `--whole` давал «ватную» речь и обрезанные концы слов, пользоваться им не стоит.

## 8. Нормы длины

Голос идёт примерно **2,7 слова в секунду**. Для ролика на 80–100 секунд нужно 245–290 слов. 228 слов дали 76,8 с, 249 слов дали 84,6 с.

Если дубли «поплыли» на длинном тексте, озвучь частями по 6–8 фраз и склей с учётом времени слов из `best_words.json`.

## 9. Если не работает

- **`torch.cuda.is_available()` = False.** Поставлен torch без CUDA. Удали его и поставь заново с `--index-url https://download.pytorch.org/whl/cu124`.
- **«жду GPU: другая озвучка ещё идёт».** Это нормально: скрипт пускает по одной озвучке на видеокарту, остальные ждут в очереди. Замок снимается сам при завершении процесса. Если ничего не идёт, а сообщение висит, закрой зависший процесс Python.
- **Сбой CUDA.** Скрипт сам повторяет попытку до 8 раз. Если видеокарту делит с играми и браузером, закрой лишнее.
- **`GPU не отвечает`.** Все 8 попыток исчерпаны. Освободи видеокарту и запусти заново, кеш сохранит уже готовое.
- **Ошибка про `token_type_ids` в RUAccent.** В `text_tools.py` уже есть патч. Если ошибка осталась, значит поставилась другая версия: ставь ровно `ruaccent==1.5.8.3`. Для озвучки RUAccent не критичен: если он недоступен, в `disputed.txt` просто запишется причина.
- **Слово произносится неверно.** Сначала ударение (раздел 6). Если ударение верное, а слово всё равно искажено, переформулируй фразу или разбей предложение иначе.
- **Обрыв слова в конце.** Увеличь число дублей `--takes 5`, при необходимости перегенерируй: подбор сидов уже встроен.
- **Расхождения в `report.json` вроде «60 → шестьдесят й»** происходят от разбивки слов при распознавании и на звук не влияют.
- **Голос непохож на оригинал.** Почти всегда виноват образец: шум, музыка, неточная расшифровка или слишком нейтральная интонация. Замени `ref.wav` и `ref.txt`.

## 10. Структура папки

```
voice-clone\
  voiceover.py  text_tools.py  stress_dict.txt
  venv\            окружение F5
  venv-text\       окружение текста и проверки
  model\
    F5TTS_v1_Base\vocab.txt
    F5TTS_v1_Base_v4_winter\model_212000.safetensors
  voices\ИМЯ\      ref.wav, ref.txt, (ref_marked.txt)
  texts\           твои тексты
  out\ИМЯ\         результат; out\_cache — кеш генераций
```
