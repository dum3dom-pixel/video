## Git

`.gitignore` исключает `*.mp4`, `out/`, логи и ключи: готовые ролики живут только на диске, бэкапа в git у них нет. Образец голоса друга `tools/voice-pipeline/voices/friend/ref.wav` не выкладывать в публичный доступ без его согласия. Новые файлы `final-video` пока не закоммичены.

## Открытые вопросы

- [ ] **Согласие друга на голос** и лицензия модели для монетизации не проверены. Без этого публичный выпуск под вопросом.
- [ ] **Свой узнаваемый признак канала** не выбран: рисунок из той же семьи, что у «420».
- [ ] **Длина 60 с не подтверждена данными.** Это решение пользователя; хиты автора длиннее, медиана 110 с.
- [ ] **Ролики 79–89 с** («Голосовое», «Ссора», «Я просто пошутил») длиннее нормы: решить, оставлять или резать.
- [ ] Живые звуки к сценам не добавлены: нужны настоящие записи и разрешение на скачивание.
- [ ] Поднять живость голоса можно только образцом на 1–2 минуты с разными эмоциями.
