# Загрузка YouTube Shorts

Открой `Upload YouTube Short.cmd` в корне проекта. Выбери паспорт выпуска с расширением `.youtube.json`. Команда покажет канал и название перед отправкой. После обработки видео она добавит обложку, при необходимости добавит видео в плейлист и откроет страницу ролика в Studio.

## Один раз подключить YouTube

1. Создай или выбери проект в [Google Cloud](https://console.cloud.google.com/projectselector2/home/dashboard).
2. Включи [YouTube Data API v3](https://console.cloud.google.com/apis/library/youtube.googleapis.com).
3. В [Google Auth Platform](https://console.cloud.google.com/auth/overview) настрой экран согласия. Если приложение внешнее и в режиме Testing, добавь свой Google-аккаунт в Test users.
4. В [Clients](https://console.cloud.google.com/auth/clients) выбери Create client → Desktop app и скачай JSON.
5. Снова открой загрузчик и выбери скачанный JSON. В браузере подтверди доступ для нужного канала YouTube. Локальные данные подключения сохраняются в профиле Windows, в `%LOCALAPPDATA%\ShortsPublisher`. Не добавляй их в проект. Если Google отзовёт тестовый токен, загрузчик снова откроет окно входа.

## Подготовить выпуск

Скопируй `example.youtube.json` рядом с новым MP4. Укажи имена MP4 и PNG, заголовок, описание и теги. Для русского ролика оставь `language: "ru"`. Категория 27 соответствует Education. Проверь признаки детской аудитории и синтетического контента для конкретного выпуска. Поле `playlist` можно убрать, если плейлист не нужен. Для добавления в плейлист Google запрашивает более широкое разрешение YouTube.

Все новые загрузки приватные. Возрастное ограничение, платную интеграцию и время публикации проверь и установи в Studio, прежде чем открывать доступ к ролику.

При повторном запуске для того же файла на том же канале загрузчик использует сохранённый сеанс или ID. Если Studio уже содержит этот выпуск после ручной загрузки, продолжи оформление там. Загрузчик учитывает только собственные загрузки. Если YouTube сообщает, что сеанс истёк, сначала проверь список видео в Studio.

## Проверка без загрузки

```powershell
node .\tools\youtube\upload.mjs preview "C:\путь\к\выпуску.youtube.json"
```
