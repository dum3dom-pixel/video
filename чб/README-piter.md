# «Принцип Питера»: разбор larkin.life, вертикальный ЧБ-ролик, конвейер озвучки

Что сделано за эту работу:

1. Скачаны и разобраны 6 роликов Instagram-автора larkin.life.
2. По его подаче сделан свой ролик на 30 с в чёрно-белом стиле, сложнее по рисунку.
3. Собран конвейер озвучки: от текста до готового голоса одной командой, с автоматическими ударениями.

Итог: `для Ютуба/piter_bw.mp4`, 30 с, 1080×1920, 30 fps, эпизод `PiterBw`.

## 1. Разбор референса

Материалы лежат в `research/larkin-life/`: 6 mp4, расшифровки `*.txt`, листы кадров `frames/`, подробный разбор `ANALYSIS.md`.

Ролики скачиваются через `yt-dlp` без входа в аккаунт:

```bash
yt-dlp -o "%(id)s.%(ext)s" "https://www.instagram.com/reel/<id>/"
```

| Что цепляет | Как сделано у него |
|---|---|
| Хук за 3 секунды | Обвинение или парадокс: «Твой начальник — идиот не случайно», «памперсов для стариков больше, чем для детей» |
| Зритель узнаёт себя | «40 сообщений про шторы в родительском чате», «созвон на 12 человек» |
| Конкретика | Имя, год, число. Масштаб переводится в понятное: «минус Саратов» |
| Одна мысль на кадр | Заголовок на 2–6 слов, читается без звука, смена кадра каждые 3–6 с |
| Один акцент | Красный на чёрно-белом |
| Твист и закольцовка | «Навыков восемь» в середине, финал отвечает на хук |
| Сериальность | «Часть 1 из 4», «первые семь в профиле» |

Слабое место автора: статичные кадры, 1–3 героя, половина экрана пустая.

## 2. Ролик

### Текст

> Твой начальник не родился идиотом. Его до этого повысили. Принцип Питера, 69-й год. Вот лучший механик в автосервисе. Чинит всё. Его делают начальником. И теперь он лезет в каждый мотор, слесари курят, машины стоят. Выше его уже не поднимут. Так и сидит. Механика потеряли, идиота получили. И так на каждом этаже. В 2010-м итальянцы посчитали: повышать наугад выгоднее, чем повышать лучших. За это им дали Шнобелевку. Тебя не повышают? Радуйся. Ты ещё не дорос до своего идиота.

Тема и пример с механиком взяты из ролика автора и книги Питера, формулировки свои.

### Стиль

| Что | У него | У нас |
|---|---|---|
| Цвет | Чёрно-белый плюс красный | Только чёрное и белое, акцент заливкой чернью |
| Движение | Статичные кадры | Линии дорисовываются, шестерни, дым, прыжки по ступеням, рулетка, штампы с ударом |
| Массовка | 1–3 героя | Разрез конторы на 7 этажей, в каждой комнате свой начальник |
| Высота кадра | Низ пустой | Сцены на всю высоту, два этажа действия в одном кадре |
| Шутки | В тексте | Ещё и в рисунке: младенец со штампом «ПОВЫШЕН», ростомер с отметкой «ТВОЙ ИДИОТ» |

Человечек (`Man` в `shots.tsx`) сделан по скрину заказчика: круглая голова, узкая шея, прямое тело, две короткие ноги с узкой прорезью, руки-трубки. Голова, тело и руки сливаются в один контур: сначала всё рисуется чернью с запасом, сверху белым без обводки. Толщина линии постоянная при любом масштабе (`3.6 / s`). Если кисть попадает внутрь силуэта (сигарета у рта), рука рисуется поверх своим контуром.

Параметры у `Man` те же, что у `Blob` из `kit.tsx`, поэтому позы в сценах менять не пришлось. `Blob` и другие ролики не затронуты.

## 3. Озвучка

Лежит в `C:\Users\daatva\voice-clone` (вне репозитория). Голос: локальный клон F5-TTS, образец `voices/friend`.

```bash
cd C:\Users\daatva\voice-clone
venv\Scripts\python.exe voiceover.py texts\piter.txt --name piter_auto
```

`--dry` только готовит текст, без генерации. Ещё есть `--takes`, `--speed` (по умолчанию 0,9), `--nfe`, `--voice`.

| Шаг | Чем | Что происходит |
|---|---|---|
| 1 | `rutextnorm` | Числа и даты становятся словами: `69-й` → «шестьдесят девятый» |
| 2 | `silero-stress` | Ставит `+` перед ударной гласной. С односложных слов и слов с «ё» плюс снимается |
| 3 | `stress_dict.txt` | Свои правки перекрывают автоматику |
| 4 | RUAccent | Второе мнение: где расходится с silero, слово попадает в `disputed.txt` |
| 5 | F5-TTS | 3 дубля, образец тоже размечен (`ref_marked.txt`) |
| 6 | `faster-whisper` | Сверка дублей с текстом, штраф за паузы длиннее 0,6 с, выбор лучшего |
| 7 | `ffmpeg loudnorm` | Громкость −15 LUFS |

Результат в `out\<name>\`: `best.wav`, `best_words.json`, `marked.txt`, `disputed.txt`, `report.json`.

Текстовые библиотеки стоят в отдельном `venv-text`, чтобы не ломать зависимости F5.

### Почему silero-stress

Сравнение на тексте про Питера (54 многосложных слова) и 16 фразах с омографами:

| | Текст | Омографы | Запуск |
|---|---|---|---|
| silero-stress | 53 из 54 | 16 из 16 | Работает сразу |
| RUAccent (turbo3.1) | 54 из 54 | 15 из 16 | Нужна заплатка `token_type_ids`, она в `text_tools.py` |

Единственное расхождение silero в тексте — «Шнобелевку», где оба варианта спорные. Тест маленький и разметка ручная: это проверка на наших текстах, а не общий рейтинг.

### Тест разметки на слух

| Дубль | Что услышало распознавание |
|---|---|
| Без разметки | «слесарей курят» вместо «слесари курят» |
| `+` только в тексте | Сбой: «с леса рекурят» |
| `+` в тексте и в образце | Без ошибок, заказчик выбрал этот вариант на слух |

### Как поправить ударение

Добавить слово с плюсом в `stress_dict.txt`, по одному на строку, каждую форму отдельно, и запустить команду снова:

```
шн+обелевку
```

## 5. Что не проверено и что слабо

- Распознавание не различает ударения. Итог проверяется только на слух.
- «Шнобелевку» в словаре поставлена как шн**О**белевку. Silero ставит шноб**Е**левку. Выбрать на слух.
- Музыки и звуковых эффектов нет, только голос.
- Факты (1969, Шнобелевская премия 2010) взяты из ролика автора и из памяти, по первоисточникам отдельно не сверялись.
- Сверка дублей считает отличием написание вроде «69-й», поэтому процент совпадения немного занижен. На выбор дубля это не влияет.
- Ролик близок к чужому: тема, структура и пример с механиком. Для публикации лучше брать свою тему.
- Голос клонирован с друга, для публичного канала нужно его согласие.
- Лицензии моделей F5 для монетизации не проверены.
- Ничего не закоммичено.
